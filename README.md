# Rubis Music — releases

Release feed for the Rubis Music macOS player (source is private).

- **Download:** grab the latest `RubisMusic-x.y.z.dmg` from
  [Releases](https://github.com/Di-kairos/rubis-releases/releases), open it and
  drag the app to Applications. First launch: right-click → Open.
- **Updates:** the app checks `appcast.xml` in this repo (Sparkle) and updates
  itself.
